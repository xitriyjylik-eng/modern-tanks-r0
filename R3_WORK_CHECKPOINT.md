## Следующий шаг при команде «Продолжай»

1. Сначала перечитать этот файл и проверить фактический HEAD ветки.
2. Продолжить загрузку статического мира с части 3/6 до 6/6.
3. Проверить полноту всех R3-файлов: `main.c`, `resources.res`, ресурсы карты и workflow.
4. Запустить GitHub Actions для `r3-map-camera`.
5. Если сборка упадёт — открыть логи конкретного job, исправить причину и повторить сборку.
6. При успешной сборке скачать artifact с `rom.bin`, проверить ROM и SHA-256.
7. Не сливать R3 в `main` без успешной сборки и отдельного подтверждения/приёмки.

## Правило работы по времени

На один запрос использовать примерно до 20 минут активной работы. При приближении к лимиту не начинать длинный новый этап. Вместо этого обновить этот checkpoint: указать точный HEAD/коммит, что завершено, на чём остановлено, что осталось и какое первое действие выполнить после следующей команды «Продолжай».

Цель правила: каждый запрос должен либо завершать самостоятельный этап, либо оставлять однозначную точку продолжения без повторного разбора проекта.

# MAP 01 — статус реализации

Дата: 2026-09-10

## Для чего выполняется эта работа
Собрать большую цельную карту ручной композиции по утверждённому визуальному эталону и запустить её на Sega Mega Drive с плавной камерой, без видимой процедурной «плитки» и без длинной загрузки всей карты целиком.

Эта работа теперь является частью **R3** и ведётся до полного production-ready состояния Map 01. Общий R3-трекер: `../R3_MAP01_PRODUCTION_PIPELINE.md`.

## Основа — зафиксировано
- главный WORLD_ART: точный утверждённый master 1536×1152;
- без масштабирования и регенерации;
- 108 технических секторов по 128×128, границы игрок не должен видеть;
- старый план 4096×3072 / 192 сектора отменён;
- старый художественный R3 background не является целевой картой; используется только проверенная техническая база камеры/рендера.

## Z01 — центральная деревня — ВЫПОЛНЕНО ДО ТЕХНИЧЕСКОГО PROOF
- WORLD_ART;
- TERRAIN + COLLISION;
- OBJECTS + EVENTS;
- SPAWN;
- runtime loader и battle-state integration;
- потоковый вывод нового WORLD_ART;
- SGDK 2.11 build: ROM 393216 bytes, SHA-256 `6dca7090feb2dce2e4a1d68d8c6cac84fc59ce0f08db00d22acaef2964ebc144`;
- BlastEm NTSC подтвердил вход в бой, движение камеры, неподвижный HUD/нижнюю панель и возврат к меню.

Экспериментальные fuzzy/скриншотные CI-gates не являются отдельным этапом разработки. Возвращаться к ним только при реальной регрессии.

## Z03 — северный водопад — TERRAIN/COLLISION ВЫПОЛНЕНО
- production crop: master bounds `[384,0,1152,512]`;
- размер crop: 768×512;
- 24 сектора 128×128;
- содержит водопад, верхнюю реку, острова, северный мост и стык с Z01;
- crop является точной вырезкой утверждённого master без масштабирования/генерации;
- TERRAIN: 96×64 = 6144 ячеек;
- COLLISION: 96×64 = 6144 ячеек;
- overlap с Z01: 2560 ячеек каждого слоя унаследованы cell-for-cell;
- 24 sector-пары terrain/collision подготовлены;
- validation: PASS;
- TERRAIN SHA-256 `48de0e7a6a187fd48827dfe8dc23f9dc8c980b7536e9506fff77b2cc76862c8e`;
- COLLISION SHA-256 `74763706715a20fa8c808793f60a1126c964c9d64f1749ea6af449b1233a8e7c`.

### Следующее действие
Z03 `OBJECTS + EVENTS`. После этого — `SPAWN + runtime`, затем интеграционная проверка и переход к следующему связанному участку.

## Правило против зацикливания
Каждый участок проходит конечный конвейер: `WORLD_ART scope → TERRAIN/COLLISION → OBJECTS/EVENTS → SPAWN/runtime → интеграционная проверка → следующий участок`. CI — средство проверки, а не самостоятельная цель.

`main` не изменять/не сливать до явной пользовательской приёмки новой карты и R3.

# MAP 01 / REGION 1 — рабочая реализация

Главный художественный источник — утверждённая пользователем карта. Планировочный референс используется только для зон и связей; при конфликте художественный master имеет приоритет.

## Фактическая геометрия
- WORLD_ART master: **1536×1152 px**;
- технический сектор: **128×128 px**;
- сетка: **12×9**;
- всего: **108 секторов**.

Ранний план 4096×3072 / 16×12 / 192 сектора устарел и больше не применяется. Карта не масштабируется ради технической сетки.

## Принцип
География зафиксирована цельным авторским изображением. Автоматизация разрешена для нарезки, сериализации, конвертации и проверки, но не для создания или перестановки лесов, дорог, рек, зданий, руин и болот.

## Производственная очередь
1. Z01 центральная деревня — WORLD_ART + TERRAIN + COLLISION + OBJECTS + EVENTS + SPAWN + runtime: технически выполнено.
2. Z03 северный водопад/верхняя река/северный мост — WORLD_ART production scope подготовлен.
3. Сейчас: ручная разметка Z03 TERRAIN + COLLISION.
4. Затем: Z03 OBJECTS + EVENTS → SPAWN/runtime → интеграционная проверка.
5. Далее тем же конечным конвейером закрываются остальные соседние зоны до полной Map 01.

`main` не считать новой картой принятой и не сливать без явной пользовательской приёмки.

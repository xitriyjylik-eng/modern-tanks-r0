# MAP 01 / REGION 1 — реализация

Это рабочая структура первой большой карты.

Главный художественный источник: `PROJECT_SOURCE/references/MAP_01_VISUAL_REFERENCE_APPROVED.png`.
Второй референс используется только для логики зон и связей.

## Размер
- master: 4096×3072 px;
- сектор: 256×256 px;
- сетка: 16×12;
- всего: 192 сектора.

## Важное
Сетка не определяет внешний вид. Она не должна быть заметна игроку.
Мир рисуется вручную как цельное полотно. Скрипты не имеют права процедурно создавать географию.

## Состояние
Структура, зоны, связи и форматы слоёв реализованы.
Художественный слой `WORLD_ART` пока не перенесён в production-master.

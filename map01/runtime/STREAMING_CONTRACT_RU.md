# Контракт потоковой загрузки Map 01

1. Камера работает в мировых координатах master-space 4096×3072.
2. Активный сектор определяется как `floor(x/256), floor(y/256)`.
3. Renderer держит активный сектор и соседние сектора, необходимые для видимого окна и запаса.
4. Новый сектор должен быть загружен до того, как его пиксели попадут в видимую область.
5. Границы 256×256 являются только техническими; художественные швы между секторами запрещены.
6. Если единый SGDK MAP/tileset не сохраняет мастер без потерь, используются локальные графические страницы/банки и потоковая подгрузка.
7. Художественный master не упрощается заранее ради дедупликации тайлов.
8. Проверенная R3-логика ускорения/торможения камеры сохраняется как база; мировые bounds переводятся на новую Map 01.
9. Процедурная генерация географии в runtime и build pipeline запрещена.

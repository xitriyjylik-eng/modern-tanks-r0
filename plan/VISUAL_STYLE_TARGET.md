# Modern Tanks — утверждённая визуальная спецификация

Статус: **SOURCE OF TRUTH для будущей настройки главного меню и последующей графики игры**.

Эта спецификация выведена из двух утверждённых владельцем образцов от 2026-09-08:
1. игровой экран с рекой/мостом/лесом/деревней и HUD;
2. лист мини-спрайтов T-1/T-2/T-3/T-4 с 8 направлениями и примером на карте.

Старые визуальные образцы ландшафта и старые условные модели танков не использовать.

## 1. Базовая цель платформы

- Runtime: настоящий Sega Mega Drive / Genesis ROM через SGDK.
- Нативное игровое разрешение: **320x224**.
- Базовая сетка: **8x8 px tiles**.
- Масштаб игровых танков на карте: **16x16 px**.
- Увеличенный справочный/гаражный размер танка: **32x32 px** или больше только на специальных экранах.
- Рендер: hard pixel edges, nearest-neighbour, без blur, bilinear filtering и сглаживания.

## 2. Общий художественный язык

- Стиль: насыщенный детализированный **16-bit top-down military pixel art**.
- Не использовать плоские геометрические прямоугольники как конечную графику.
- Каждый объект должен иметь читаемый материал: металл, дерево, камень, вода, трава, грунт.
- Свет: сверху-слева; тень/окантовка преимущественно снизу-справа.
- Контур объектов: 1 px тёмный, локально 2 px на крупных объектах.
- Внутри объектов: 3–5 ступеней тона вместо одного заливочного цвета.
- Никаких больших однотонных областей и очевидного повторяющегося клетчатого ковра.

## 3. Цветовой язык

### UI / логотип
- фон: почти чёрный / очень тёмный navy;
- рамки: тёмный steel-blue + светлый cyan/steel highlight;
- основной текст: холодный off-white;
- активный акцент: жёлтый/золотой;
- MODERN: серебристо-белый металл;
- TANKS: оранжево-золотой градиент из дискретных pixel-art ступеней.

Рекомендуемые ориентиры RGB до квантизации Mega Drive:
- near black: `#020B11`
- deep navy: `#0A2637`
- steel blue: `#1D5066`
- light steel: `#75B4D2`
- off-white: `#E7EEF0`
- orange: `#F6A314`
- yellow/gold: `#FFD246`
- dark orange: `#9A5A1D`

### Ландшафт
- тёмный лес: `#17361E`
- forest green: `#48622A`
- olive: `#6E743A`
- dirt/tan: `#AF804D`
- brown: `#6B5A39`
- deep water: `#073F77`
- water mid: `#08548E`
- water highlight: `#3A93C3`
- stone dark: `#4E4E45`
- stone light: `#8A8A78`

### Классовые цвета танков
Цвет класса должен быть одинаков во всех экранах, HUD и меню:
- **T-1** — зелёный;
- **T-2** — сине-стальной;
- **T-3** — золотисто-жёлтый/песочный;
- **T-4** — красный.

## 4. Танки — обязательный стандарт

- Вид строго сверху.
- Игровой размер: **16x16 px**.
- **8 направлений** движения/корпуса.
- Один основной ствол; никаких случайных/лишних дул.
- При 16x16 должны оставаться различимы: гусеницы, корпус, башня, направление ствола и характер класса.
- Силуэты классов различаются не только цветом:
  - T-1: компактный, узкий, лёгкий;
  - T-2: средний, сбалансированный;
  - T-3: широкий, массивный, тяжёлый;
  - T-4: низкий/агрессивный штурмовой силуэт.
- Для каждого класса требуется отдельный sprite sheet 8 направлений.
- Нельзя заменять танк пиктограммой или прямоугольной условной фигурой.

## 5. Ландшафт

Карта должна использовать язык утверждённого игрового образца:
- детальная трава нескольких оттенков;
- грунтовые дороги с колеёй, неровными краями и локальными вариантами;
- река с 3–5 уровнями синего, светлыми бликами и неровным каменистым берегом;
- деревянные мосты с отдельными досками/опорами;
- плотные хвойные/лиственные кластеры;
- камни и скальные группы;
- каменные стены;
- деревянные дома, ящики, бочки, заборы;
- кратеры, следы гусениц, разрушения;
- объекты строятся кратно 8 px, но визуальная форма не должна выглядеть как сетка.

## 6. UI-язык

- Панели: прямоугольные, military/industrial, без современных rounded corners.
- Фон панели: почти чёрный/тёмно-синий.
- Внешняя рамка: 1–2 px steel blue.
- Внутренний highlight: 1 px более светлого оттенка.
- Допустимы болты/угловые маркеры.
- Шрифт: собственный pixel font, без TTF-downscale и антиалиасинга.
- Кириллица должна быть такой же чёткой, как латиница.
- Заголовки: uppercase, компактные, высокая контрастность.

## 7. Параметры будущего главного меню R2

Главное меню должно использовать тот же художественный язык, что и игровой экран, а не отдельную упрощённую стилистику.

### Композиция
- экран: **320x224**;
- battlefield landscape занимает весь фон;
- отдельную нижнюю панель `танки / параметры / карта` в главном меню **не использовать**;
- отдельный декоративный движущийся танк **не использовать**;
- логотип MODERN TANKS — крупный верхний фокус;
- центральная панель содержит только канонические пункты:
  - ИГРАТЬ
  - ГАРАЖ
  - СТАТИСТИКА
  - НАСТРОЙКИ
- фон непосредственно под панелью должен быть визуально спокойнее, чтобы не ухудшать чтение.

### Ориентировочные размеры при 320x224
- логотип: примерно **176–208 x 48–60 px**;
- центральная панель: примерно **136–156 x 92–108 px**;
- строка меню: **12–16 px высотой**;
- selector: тонкая золотая рамка/стрелки, а не крупная заливка;
- поля безопасности от краёв экрана: минимум **8 px**.

### Допустимая анимация
- selector pulse: да, лёгкий;
- минимальное мерцание воды/огня/дыма: допустимо позже, если не мешает VRAM/CPU;
- самостоятельный ездящий декоративный танк: нет.

## 8. Рекомендуемое распределение 4 палитр Mega Drive

Это стартовая схема, допускается перераспределение после ResComp-аудита:
- PAL0: UI / logo / text / yellow selector;
- PAL1: foliage + earth;
- PAL2: water + stone + wood/buildings;
- PAL3: tank/effects accents, shared dark metal, explosions.

Важно: финальное распределение определяется реальным tile/sprite usage, но визуальный результат не должен деградировать до плоских 2–3 цветных пиктограмм.

## 9. Acceptance для визуального меню

R2 нельзя принимать только потому, что CI зелёный. Перед owner-test оно должно пройти ручное визуальное сравнение:
- стиль меню совпадает со стилем утверждённого игрового экрана;
- фон по плотности деталей и материалам выглядит как тот же мир;
- логотип и UI имеют тот же steel/navy/orange язык;
- отсутствуют старые клетчатые/примитивные заглушки;
- танки, если присутствуют на фоне, соответствуют утверждённым 16x16 моделям и 8 направлениям;
- нет нижнего tank/stat/minimap HUD;
- нет декоративного moving tank;
- текст читаем на реальном 320x224;
- после перехода в TEST BATTLE/GARAGE и назад R1 residue checks остаются `ERR:00`.

## 10. Запреты

- не использовать старую DEV-графику;
- не использовать старые условные танки;
- не использовать Granada art/assets;
- не изменять идею Modern Tanks;
- не заменять runtime-графику отдельной AI-картинкой;
- AI/generated изображения допустимы только как утверждённые визуальные reference targets; runtime assets должны быть реально адаптированы под SGDK/Mega Drive.

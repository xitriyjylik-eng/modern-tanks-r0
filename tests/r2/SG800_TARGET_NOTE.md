# SG800 target note

SG800 is treated as an MD/Mega Drive emulator host for user-supplied games. The Modern Tanks deliverable remains a real Mega Drive/Genesis ROM built by SGDK. HDMI/4K marketing describes output/upscaling, not a 4K game framebuffer. R2 therefore targets maximum practical Mega Drive-quality 320x224 menu art while retaining emulator portability to PC.

R2 remains unaccepted until direct target visual approval. R3 stays blocked.
